# Security policy

## Reporting a vulnerability

Report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/javohir73/mcp-server-canvas-lms/security/advisories/new).
Include reproduction steps, affected versions, and impact when it is safe to do
so. Please allow maintainers time to investigate before public disclosure.

Do not file secrets, Canvas tokens, private course data, or vulnerability
details in a public GitHub issue. If a token may have been exposed, revoke it
in Canvas immediately and create a replacement.

Use the public [issue tracker](https://github.com/javohir73/mcp-server-canvas-lms/issues)
only for non-sensitive bugs and feature requests.
